# 口水巾纸样生成器

原生微信小程序版本的口水巾纸样生成器，支持三角巾、围兜款、花瓣款和 O 型款-new。

## 导入

1. 使用微信开发者工具选择“导入项目”。
2. 选择本目录 `/Users/mengfanmin/www/bib-pattern-miniapp`。
3. 当前 `project.config.json` 使用 `touristappid`，正式开发时替换为自己的小程序 AppID。
4. 基础库建议使用 2.19.4 或更高版本，以支持 Canvas 2D 节点接口。

## 主要能力

- 参数变化后即时重绘纸样。
- 脖围范围 20–50cm，步进 0.5cm。
- 缝份固定 1cm，支持显隐。
- O 型款拥有独立的圆形内圈、圆润顶部连接和独立锁扣定位点。
- 缝份由闭合轮廓整体向外偏移生成，并进行自交校验。
- 保存图片和纸样打印均导出高清 PNG；打印按钮会提示用户保存后按 100% 比例打印。

## 目录说明

- `pages/index/`：小程序主页面、控件和交互。
- `utils/pattern-geometry.js`：厘米坐标系下的轮廓、偏移和几何校验。
- `utils/pattern-renderer.js`：Canvas 2D 绘制、尺寸标注和5cm比例尺。

## 纸样说明

当前图形是交互与视觉稿，围兜款、花瓣款和 O 型款在实物样片验证前不代表生产定版。打印前请用图中的 5cm 校准框检查打印机是否按 100% 实际大小输出。
